INDIVIDUAL CRITICAL TASK SUMMARY

Task 081-68W-0237: Place an Intraosseous Device

You have practiced essential steps for establishing intraosseous access using the EZ-IO system at the humeral insertion site. This skill is critical for providing vascular access when traditional IV access is difficult or impossible in tactical and emergency settings.

KEY POINTS TO REMEMBER:

  • Always observe BSI precautions
  • Use aseptic technique throughout
  • Position driver perpendicular (90°) to bone
  • Never attach syringe directly to hub - use extension set
  • Flush with 5-10mL saline, observe for infiltration
  • Never recap needles - sharps container only
  • Document all procedures IAW TCCC guidelines

PURPOSE

The Individual Critical Task Virtual Simulation (ICTSVS-001) is a web-based training aid designed to supplement hands-on skills training for Army Medical Department (AMEDD) personnel. It provides standards-referenced, step-gated performance simulation for selected Individual Critical Tasks as defined in current Soldier's Manuals and Trainer's Guides.

This system is a training aid only. It is not a medical device, does not constitute medical advice or doctrine, and does not replace live skills training, evaluator certification, or official Army task performance records.

INTENDED USERS

Students and instructors enrolled in or supporting approved Army medical training programs at MEDCoE and subordinate schools. Additional MOS/AOC libraries will be released as validated content becomes available.

APPROVAL AUTHORITY

Content is proponent-reviewed and doctrine-aligned per publications listed on the REFERENCE screen. Specific approval authority and review chain documentation is on file with the developing office.

SECTION B — SCOPE AND LIMITATIONS

✓ SIMULATED IN THIS SYSTEM
  • EZ-IO humeral head insertion site (Task 081-68W-0237)
  • BSI (gloves and eye protection) as a mandatory first step
  • 10-step sequential procedure with step-gated validation
  • Extension set attachment before syringe (safety gate)
  • Saline flush and site assessment steps
  • Sharps disposal (without recapping)
  • SF 600 documentation step
  • 68Q controlled substance inventory (Task 081-68Q-0034)
  • Go/No-Go evaluation with error tracking and timed metrics
  • Knowledge assessment (10-question per-task quiz)
✕ NOT SIMULATED
  • Haptic or tactile feedback (needle resistance, flush resistance)
  • FAST1 sternal IO insertion
  • Tibial and other alternate IO insertion sites
  • Sterile field setup and maintenance
  • Live patient assessment (actual pain, vital signs, responsiveness)
  • Medication administration via IO route
  • IO dwell time / removal procedures
  • Network transmission of training records (fully offline)

HOW TO INTERPRET RESULTS

  • Errors counter: Increments on each incorrect drop (wrong tool, wrong target, out-of-sequence). High errors with low time may indicate guessing.
  • Time: Displayed in MM:SS. No per-step time standard is enforced in simulation; use time holistically. Compare to doctrinal task time standards from the SM-TG.
  • Step completion: Each step is binary — completed or not. All 10 steps must complete for GO.
  • Knowledge assessment: 100% required. A score below 100% triggers mandatory remedial training before the learner can see their certificate.
  • Pass/Fail: Simulation GO does not constitute official task qualification. Use results to guide remediation and hands-on evaluation scheduling.

ACCESSING INSTRUCTOR / DEBUG MODE

Press the D key at any time during a training simulation to toggle the debug panel. The debug panel allows instructors to:

  • Show hotspot overlays on the scene canvas (visual indicator of valid drop zones)
  • Skip the current step (useful for demonstrating later steps without completing prior steps)

Debug mode is keyboard-only and not visible to learners unless the instructor activates it. It does not alter scoring.

SUGGESTED DEBRIEF QUESTIONS — Task 081-68W-0237 (IO Placement)

  • What is the minimum BSI standard before beginning any invasive procedure?
  • Why is the extension set attached before the syringe, not after?
  • What angle should the IO driver be positioned at relative to the bone surface?
  • How do you confirm correct IO placement before beginning infusion?
  • What are the indicators of IO infiltration, and what action do you take?
  • Why are needles never recapped, and what are the consequences of a needlestick?
  • What information must be documented on the SF 600 after IO placement?

SUGGESTED DEBRIEF QUESTIONS — Task 081-68Q-0034 (Pharmacy Inventory)

  • Who are the two required witnesses for controlled substance inventory?
  • What constitutes a discrepancy, and what is the immediate reporting chain?
  • What are the consequences of failing to report a shortage or overage?
  • What documentation is required after each controlled substance inventory?

COMMON LEARNER ERRORS

  • Attempting to attach syringe directly to IO hub (bypassing extension set)
  • Skipping or delaying BSI step — BSI is a mandatory first action
  • Incorrect drop zone — dragging to scene area rather than specific target
  • Attempting to proceed out of sequence in instructional mode

OFFLINE SETUP

  1. Download or copy the entire simulation folder to a local drive or USB drive.
  2. Keep all files in the same directory — do not move individual files out of the folder.
  3. Open index.html in Chrome or Edge. No web server or internet connection is required.
  4. If opening from a USB drive on a restricted network computer, ensure the browser is not blocking local file access (check browser security settings or use an instructor workstation).

KNOWN BROWSER ISSUES

  • Safari (macOS/iOS): Drag-and-drop behavior may be inconsistent. Chrome or Edge recommended.
  • iOS / iPadOS: Touch drag-and-drop is not fully supported. Use a mouse-connected device for full simulation functionality.
  • Firefox: Navigation and screen routing work correctly. Drag-and-drop is functional but may feel slightly different from Chrome/Edge.
  • Zoomed-in browsers: If browser zoom is above 100%, drop zones may appear offset. Reset to 100% zoom (Ctrl+0) if drops are not registering.

IF SOMETHING BREAKS

  1. Refresh the page (F5 or Ctrl+R). This resets all state.
  2. If a saved session is causing issues, clear localStorage: open browser DevTools (F12) → Application tab → Local Storage → Clear All.
  3. If images are missing, verify all PNG files are in the same folder as index.html.
  4. If the issue persists, report it using the contact information on the CHANGELOG screen.
